/* Living inside a template that was written for legal text.
   ---------------------------------------------------------
   This theme has no working generic page template. All 35 pages on the site
   carry a bespoke PHP file, and the default one prints nothing whatsoever, so
   a page left on it answers 200 with an empty body however good its content
   is. The legal pages are the only ones that call the_content(), so that is
   the template these pages have to borrow, and it brings two things with it:

       <section class="content container">     a narrow, padded column
         <h1 class="page-title">…</h1>         the WordPress page title

   Both are undone below. The design is full bleed at 1920 and carries its own
   H1, and a second one would be a heading-order fault as well as a visual one.
   The page title still does its work in menus, in search and in the tab.

   The template also enqueues privacity.min.css, which sizes the <main> itself:

       @media (min-width: 1200px) { main { width: 78.25%; margin-inline: auto } }

   78.25% of 1905 is 1490, which is exactly the column the page came out in.
   That one has to be undone at <main>, not at the section inside it, along
   with the 98px it reserves above the first paragraph of a legal document.

   Two selectors for each job: :has() where the browser supports it, and a
   class that carousel.js puts on the same element where it does not. Neither
   can match anywhere else on the site, since both need a .gs on the page. */
.gs-main,
main:has(.gs) { width: auto; max-width: none; margin-inline: 0; padding-top: 0; margin-bottom: 0; }

/* The theme leaves 19px between the end of <main> and the top of the footer.
   On its own pages that sits inside the 70px of air privacity.min.css gives
   the main, and reads as spacing. Here the page ends on a full bleed
   photograph, the 70px is undone above, and what is left shows as a pale strip
   under the last row. It survives zeroed margins on both boxes and is not a
   line box, so rather than chase it with a magic negative margin the seam is
   simply given the footer's colour: it then reads as the footer beginning a
   few pixels earlier, which is what it looks like anyway. Every other part of
   the body is covered by the header, the block or the footer. */
body:has(.gs) { background-color: var(--color-arena); }

/* Matched on a descendant rather than a child. A block pasted over an older one
   can end up wrapped in stray markup, and a single unclosed tag is enough to
   put the .gs a level deeper than expected. When that happened the child
   selector stopped matching and the page snapped back to the 1320px Bootstrap
   column, which reads as the design breaking rather than as the paste being
   wrong. */
.gs-host,
.content.container:has(.gs) { max-width: none; padding: 0; margin-inline: 0; }

.gs-host > .page-title,
.content.container:has(.gs) > .page-title { display: none; }

/* The same stylesheet dresses bare elements for a legal document: a Gill Sans
   body, 14 to 16px paragraphs on a 19px rhythm, and `main ul li` with a "• "
   marker, which lands on the li and so beats a list-style inherited from the
   ul. That is what put bullets over the four names in the index row.

   Undone to the values these elements have with no page stylesheet at all,
   which is what the design was drawn against. :where() keeps the specificity
   at a single class so the components further down this file, which are also
   single class, win on source order; anything of mine that is more specific
   wins outright. */
.gs :where(p, ul, ol, li, figure, blockquote, h1, h2, h3, h4, h5, h6) {
  margin: 0;
  padding: 0;
  font: inherit;
  letter-spacing: inherit;
  text-transform: none;
  list-style: none;
}

/* One of its rules carries a pseudo-class, `main p:not(:last-of-type)`, and so
   outranks the line above. Matched here rather than raised across the board,
   which would start outranking the components too. Every paragraph in this
   design sets its own top margin and leaves the bottom at zero. */
.gs :where(p):not(:last-of-type) { margin-bottom: 0; }

/* Two Bootstrap utilities the markup uses. The standalone pages pull Bootstrap
